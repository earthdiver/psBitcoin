# 例01〜07の速度比較

この記録は256点（v1）方式の結果です。下位8ビットをまとめた方式との比較は[別レポート](generator-low8-2026-09-11.md)に記録しています。

計測日: 2026-09-11。単位はミリ秒、各条件3回の中央値。小さいほど高速です。

## 計測条件

- 各例・条件・試行で新しいプロセスを使用し、計測自体は直列実行。
- 通常版とFast版は同じ例を実行。例の実行時間を計測し、プロセス起動・ライブラリ読み込み・出力検証・画面描画は含めません。
- 「Fast生成」はファイルもメモリのテーブルもない状態。「Fast読込」は保存済みファイルを別プロセスで初めて使う状態です。OSのファイルキャッシュはクリアしていません。
- 「通常2回目」「Fastメモリ」は、それぞれ同じプロセスで同じ例をもう一度実行した時間です。ウォレットの再読み込みは行いません。
- 新しいプロセスでの初回にはPowerShell/.NETの初回実行コストも含まれます。テーブルだけの生成・読込時間ではありません。
- ソースと単語リストは同じローカル一時ディレクトリへコピーし、キャッシュもローカル一時ファイルを使用。ユーザーの通常キャッシュは使用・削除しません。
- 全実行で出力を既存の.outと照合。空白・空行も保持し、改行コードのみLFに統一。
- 01と05は固定基点乗算を使わず、Fast版でもテーブルは未生成です。

```powershell
./tests/Benchmark-Examples.ps1 -Repetitions 3
```

## 結果の読み取り

- 02・03・06・07は両PowerShell環境で、テーブル生成を含む初回から通常版より高速でした。
- 04は生成・読込を伴う初回が通常版より遅く、メモリ再利用時は約1.6倍高速でした。
- 最適化対象の乗算を使う例の2回目は、PowerShell 5.1で1.58〜1.87倍、7.6.5で1.62〜2.00倍高速でした。
- 01・05には対象の乗算がありません。表の差をテーブル最適化の効果と解釈しないでください。
- 合計252回の例の実行すべてで.outと一致しました。JSONには各条件の最小・最大・全測定値も保存しています。
